# Todo App (React 19 + Typescript)

Приложение для управления списком задач.

## Стек технологий

- React 19
- TypeScript
- Vite
- React Icons
- UUID

## Инструкция к запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/yuliyaDzerviankova/todolist.git
cd todolist
```

### 2. Установка зависимостей
```bash
npm install
```
или
```bash
yarn install
```

### 3. Запуск проекта в режиме разработки
```bash
npm run dev
```
или
```bash
yarn run dev
```
После запуска проект будет доступен в браузере по адресу `http://localhost:5173/`.

### 4. Сборка для продакшена
```bash
npm run build
```
или
```bash
yarn run build
```

## Затраченное время
Суммарно на выполнение задания ушло около **2х часов**
- **0.5 ч** - Стартовый набросок логики и базовая верстка.
- **1 ч** - Рефакторинг: декопозиция, создание кастомного хука, исправление багов.
- **0.5 ч** - Тестирование и документация.
