# Todo App (React 19 + Typescript)

Приложения для управления списком задач.

## Стек технологий

- React 19
- TypeScript
- Vite
- React Icons
- UUID

## инструкция к запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/yuliyaDzerviankova/todolist.git
cd todolist
```

### 2. Установка зависимостей
```bash
npm install
```
или
```bash
yarn install
```

### 3. Запуск проекта в режиме разработки
```bash
npm run dev
```
или
```bash
yarn run dev
```
После запуска проект будет доступен в браузере по адресу `http://localhost:5173/`.

### 4. Сборка для продакшена
```bash
npm run build
```
или
```bash
yarn run build
```
